# LLM

gptcheck.py - evaluates plurality/surprisingly popular on a data set. surprisingly popular currently incrorrectly implemented.
gptlongcheck.py - evaluate plur/surp on a data set with only a single percent. uses 'naive' method to expand percents.
gptmultiple.py - creates raw data set by asking gpt to answer each question in truthfulQA dataset. currently set up for getting it to think out loud, but can easily be changed by changing the function to work without thinking.
gptmultipleprocess.py - parse raw data generated by gptmultiple and extract answers/percents.
gptprocess.py - designed for open-ended processing. We are not currently using this.
gpttest.py - designed for open-ended. not currently using.
